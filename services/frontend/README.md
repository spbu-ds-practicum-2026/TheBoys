# Веб-интерфейс и узел приложения (services/frontend)

Модуль веб-интерфейса мессенджера и узла приложения (FastAPI + Jinja2 + HTMX), полностью соответствующий техническому решению (`docs/tr.md`).

## Возможности и разделы

1. **Раздел «Музыка» (`/music`, стартовый экран):**
   - Каталог аудиофайлов распределённого кластера.
   - Полнотекстовый поиск по названию трека и исполнителю в реальном времени.
   - Воспроизведение треков через `GET /api/tracks/{id}/stream` с поддержкой заголовка `Range` (HTTP 206 Partial Content).
   - Быстрая отправка карточки трека в любой диалог (`В чат`).

2. **Раздел «Чаты» (`/chats`):**
   - Личные диалоги 1-на-1 (Алиса, Олег, Павел, Артём).
   - Поиск собеседника по логину и открытие новых диалогов (`Найти собеседника`).
   - Счётчики непрочитанных сообщений (`unread_count`) и индикаторы онлайн-статуса с указанием узла приложения.
   - Строгий порядок сообщений по `seq` без дублей и пропусков.
   - Интерактивные карточки треков (`components/message_track.html`) с синхронизированным воспроизведением.
   - Поле ввода с тактильной печатной машинкой (monospace) и отправкой карточек треков.

3. **Раздел «Импорт» (`/import`):**
   - Загрузка аудиофайлов формата MP3 (до 50 МБ).
   - 3-шаговый пайплайн: 1) загрузка на узел приложения, 2) парсинг ID3-тегов, 3) репликация на 2 узла хранения.
   - Каталог загруженных треков с безопасной отправкой в чат.

4. **Раздел «Параметры» (`/settings`):**
   - Карточка профиля участника с возможностью переключения активного аккаунта.
   - Настройки звука, стриминга, типографики и переключатель языка (EN/RU).
   - Топология кластера: узлы приложения (`app-1`, `app-2`) и узлы хранения (`storage-1`, `storage-2`, `storage-3`).

5. **Сквозной постоянный мини-плеер:**
   - Находится в нижней части интерфейса вне динамических представлений.
   - Не прерывает воспроизведение и не сбрасывает позицию при переходе между разделами.
   - Реальный элемент `<audio>` с перемоткой, громкостью и статусом реплик.

## Структура модуля

```
services/frontend/
├── main.py                    # FastAPI-приложение (роуты, HTMX-эндпоинты, Range-стриминг)
├── requirements.txt           # Зависимости frontend-узла
├── README.md                  # Документация модуля
├── static/
│   ├── css/
│   │   ├── glass.css          # Базовые переменные, монохромная тёмная палитра, системные шрифты
│   │   ├── messenger.css      # Вёрстка каталога музыки, чатов, мини-плеера, модалок
│   │   └── settings.css       # Bento-сетка настроек и топологии кластера
│   ├── img/                   # Логотип и графические ассеты
│   └── js/
│       ├── htmx.min.js        # Библиотека HTMX
│       └── messenger-ui.js    # Единое хранилище сообщений, плеер, синхронизация карточек, i18n
├── templates/
│   ├── base.html              # Базовый каркас с навигацией и постоянным плеером
│   ├── music/catalog.html     # Каталог музыки и поиск
│   ├── messenger/
│   │   ├── chats_view.html    # Совмещённый вид диалогов и чата
│   │   ├── dialogs_list.html  # Список диалогов и счётчики непрочитанных
│   │   ├── chat_window.html   # Окно сообщений и composer
│   │   └── components/
│   │       └── message_track.html # Компонент карточки трека
│   ├── import/
│   │   └── import_placeholder.html # Загрузка MP3 и репликация
│   └── settings/
│       └── settings.html      # Параметры системы
└── tests/
    └── test_ui.py             # Интеграционные тесты (HTTP, HTMX, Range-стриминг, диалоги)
```

## Запуск из корня репозитория

```bash
uvicorn services.frontend.main:app --host 0.0.0.0 --port 8000 --reload
```

## Запуск тестов

```bash
pytest services/frontend/tests/ -v
```
