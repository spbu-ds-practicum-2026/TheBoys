# Веб-интерфейс и узел приложения (services/frontend)

Модуль веб-интерфейса мессенджера и узла приложения (FastAPI + Jinja2 + HTMX), полностью соответствующий техническому решению (`docs/tr.md`) и контрактам WebSocket/мессенджера (`services/app`).

## Возможности и разделы

1. **Раздел «Музыка» (`/music`, стартовый экран):**
   - Каталог аудиофайлов распределённого кластера с каноническими UUID идентификаторами треков.
   - Полнотекстовый поиск по названию трека и исполнителю в реальном времени (`GET /api/tracks?q=...`) с поддержкой очистки по клавише ESC.
   - Воспроизведение треков через `GET /api/tracks/{id}/stream` с поддержкой заголовка `Range` (RFC 9110, HTTP 206 Partial Content, HTTP 416). Синтетический MP3-поток сформирован с точным размером фрейма 417 байт (128 kbps, 44.1 kHz stereo без padding-бита) для безошибочного декодирования в Chromium и браузерах.
   - Быстрая отправка карточки трека в любой диалог (`В чат`).

2. **Раздел «Чаты» (`/chats`):**
   - Личные диалоги 1-на-1 (Алиса, Олег, Павел, Артём) без избыточных фильтров каналов.
   - Поиск собеседника по логину через `GET /api/users?login=...` и открытие новых диалогов (`Найти собеседника`).
   - Счётчики непрочитанных сообщений (`unread_count`) с асинхронным сбросом через `POST /api/conversations/{id}/read`.
   - Монотонный строгий порядок сообщений по `seq` без дублей и пропусков. Отправка сообщений через `POST /api/conversations/{id}/messages`.
   - Интерактивные карточки треков (`components/message_track.html`) с синхронизированным воспроизведением.
   - Кнопка опций в заголовке чата открывает модальное окно сведений о собеседнике (узел подключения, онлайн-статус, репликация).

3. **Раздел «Импорт» (`/import`):**
   - Реальная загрузка аудиофайлов формата MP3 через `POST /api/tracks/upload` с сохранением и мгновенной доступностью для воспроизведения через стриминг.
   - 3-шаговый интерактивный трекер пайплайна: 1) загрузка на узел приложения, 2) извлечение ID3-тегов, 3) репликация на 2 узла хранения.
   - Каталог загруженных треков с безопасной отправкой в чат.

4. **Раздел «Параметры» (`/settings`):**
   - Карточка профиля участника с возможностью входа и регистрации (`POST /api/login`, `POST /api/register`).
   - Интерактивные переключатели тем (тёмная палитра, размытие стекла, шрифт печатной машинки monospace) с сохранением состояния в `localStorage`.
   - Топология кластера: узлы приложения (`app-1`, `app-2`) и узлы хранения (`storage-1`, `storage-2`, `storage-3`).

5. **Сквозной постоянный мини-плеер:**
   - Находится в нижней части страницы вне области HTMX-свопа, что гарантирует непрерывность воспроизведения при навигации между разделами.
   - Реальный элемент `<audio>` со скраббингом, регулировкой громкости, повтором, перемешиванием и индикацией реплик.

6. **HTMX 2.x интеграция:**
   - Прямая навигация по каноническим адресам (`/music`, `/chats`, `/import`, `/settings`) с поддержкой заголовка `HX-Request`.
   - Обработчик события `htmx:afterSwap` автоматически актуализирует активные вкладки, переводит интерфейс и гидрирует сообщения чата без рекурсивных циклов вызовов.
   - Все динамические данные экранируются через `escapeHtml` для защиты от Stored/Reflected XSS.

## Структура модуля

```
services/frontend/
├── main.py                    # FastAPI-приложение (роуты, HTMX-эндпоинты, Range-стриминг, REST API)
├── requirements.txt           # Зафиксированные версии зависимостей frontend-узла
├── README.md                  # Документация модуля
├── static/
│   ├── css/
│   │   ├── glass.css          # Базовые переменные, монохромная тёмная палитра, системные шрифты
│   │   ├── messenger.css      # Вёрстка каталога музыки, чатов, мини-плеера, модалок
│   │   └── settings.css       # Bento-сетка настроек и топологии кластера
│   ├── img/                   # Логотип и графические ассеты
│   └── js/
│       ├── htmx.min.js        # Библиотека HTMX
│       └── messenger-ui.js    # Единое хранилище сообщений, плеер, синхронизация карточек, i18n
├── templates/
│   ├── base.html              # Базовый каркас с навигацией и постоянным плеером
│   ├── music/catalog.html     # Каталог музыки и поиск
│   ├── messenger/
│   │   ├── chats_view.html    # Совмещённый вид диалогов и чата
│   │   ├── dialogs_list.html  # Список диалогов и счётчики непрочитанных
│   │   ├── chat_window.html   # Окно сообщений и composer
│   │   └── components/
│   │       └── message_track.html # Компонент карточки трека
│   ├── import/
│   │   └── import_placeholder.html # Загрузка MP3 и репликация
│   └── settings/
│       └── settings.html      # Параметры системы
└── tests/
    └── test_ui.py             # Интеграционные тесты (HTTP, HTMX, Range-стриминг, диалоги, auth)
```

## Запуск из корня репозитория

```bash
uvicorn services.frontend.main:app --host 0.0.0.0 --port 8000 --reload
```

## Запуск тестов

```bash
pytest services/frontend/tests/ -v
```
